📝 Planner de Tarefas Personalizado
Organize suas atividades de forma simples e visual com este planner minimalista. 
Agrupe tarefas por categorias, adicione datas e horários automaticamente, e mantenha tudo sob controle com uma interface leve, moderna e intuitiva. 
Ideal para estudos, projetos pessoais ou compromissos diários, o sistema permite a criação dinâmica de tarefas e categorias, com salvamento automático em arquivo local.
